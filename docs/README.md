# Документация OpenMES

Карты API МЭШ, по которым написан клиент. Личных данных здесь нет: только пути, параметры,
поля ответов и статусы.

| Документ | Что внутри |
|---|---|
| [Карта API колледжа](college-api/README.md) | Что реально работает у студента колледжа (СПО): адреса после маршрутизации, заголовки, живые статусы |
| — [Дневник](college-api/01-diary.md) | Расписание, оценки, зачётка, ДЗ, посещаемость, профиль, уведомления |
| — [Портфолио, новости, рейтинг](college-api/02-portfolio-news.md) | Портфолио (МП-бэк и портфолио-сервис), новости, рейтинг |
| — [Сервисы](college-api/03-services.md) | Питание, сообщения, настройки уведомлений, проходы, платежи, справки |
| — [Сборка колледжа](college-api/04-college-build.md) | Чем сборка «Колледж МЭШ» отличается от школьной: id, флаги, навигация |
| [Карта API школы](school-mos-api-map.md) | Справочный список путей school.mos.ru для школы |
| [school-mos-openapi.json](school-mos-openapi.json) | Школьная OpenAPI-спецификация, из которой собрана карта школы |

Проверить любой путь вживую можно в приложении: скрытая «Консоль API» открывается семью нажатиями
на версию в настройках.
Кнопка «Разведка» прогоняет список [`ApiProbes.kt`](../feature/more/src/main/kotlin/ru/openmes/feature/more/ApiProbes.kt)
и пишет ответы в `adb logcat -s OpenMES-API`.
